# Website-Development
in this project, I was tasked to create a retro games inspired website for a young age group. I explored the requirments of the client and created a 3 pages website containing games from different eras of retro gaming.



# Project outcome
from this project, I built an understanding of how HTML, CSS and Javascript worked. I was able to learn how to design and create responsive and user - friendly websites, tailored based on specific client criteria. This project also helped me with understanding user requirments as i was able to gain feedback from a user by creating an online form.
